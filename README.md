# Madlen Lesson Planner Lite

A free lesson planner for Key Stages 1 to 3 in England. Teachers pick every option from the official curriculum, and the AI plans a five-stage lesson grounded in the selected statutory statements.

- Curriculum source: The national curriculum in England: Key stages 1 to 4 framework document (DfE, 2014), Open Government Licence v3.0.
- AI: Google Gemini, called from `api/generate.js`. The key is stored in the `GEMINI_API_KEY` environment variable on Vercel.
